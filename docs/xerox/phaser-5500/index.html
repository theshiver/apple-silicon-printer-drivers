Driver: SpliX 2.0.2 · Model id: splix-xerox-phaser-5500

Wi-Fi, network, or not detected over USB

After installing, open Terminal (⌘+Space, type Terminal), paste this and press Enter:

sudo gutenprint-add splix-xerox-phaser-5500

For a network printer, add a name and the printer's address (lpinfo -v lists what macOS can see):

sudo gutenprint-add splix-xerox-phaser-5500 MyPrinter socket://192.168.1.50

Or without Terminal: System Settings → Printers & Scanners → Add → Use: Select Software… and pick “Xerox Phaser 5500” ending in “Apple Silicon”.

Why did my Xerox Phaser 5500 stop working?

Xerox's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta, but macOS 27 marks Intel-only printer drivers as incompatible, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with SpliX 2.0.2, compiled natively for Apple Silicon.

The Xerox Phaser 5500 speaks Samsung's SPL printer language rather than PCL or PostScript, so it uses the bundled native arm64 SpliX driver rather than Gutenprint. Toner save, density and resolution are in the print dialog under Printer Features.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.

Questions

Does the Xerox Phaser 5500 work on macOS 27, macOS 26 Tahoe and Apple Silicon?

Yes. This free package adds a native arm64 SpliX driver for the Xerox Phaser 5500. It runs on every Apple Silicon Mac with macOS 12 or later, including macOS 27, without Rosetta.

Do I need to write my own Xerox Phaser 5500 driver?

No. The Xerox Phaser 5500 is already supported by SpliX, an open source driver with years of tuning for this printer. Install the package; there is nothing to write, compile or patch.

Why does my Xerox Phaser 5500 say “The printer software is not compatible with this device”?

Xerox's Mac driver for the Xerox Phaser 5500 is Intel-only, and macOS 27 marks Intel-only printer drivers as incompatible. Install this package, restart the Mac once, then unplug and re-plug the printer.
