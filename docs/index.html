Old printer, new Mac? Get it printing on Apple Silicon.

Free native (arm64) macOS driver for 3578 printers — Canon PIXMA, Epson Stylus, HP DeskJet & LaserJet, Brother, Samsung, Lexmark, Kyocera, Xerox, Ricoh, Oki, Kodak and more. Fixes “The printer software is not compatible with this device” on macOS 27 without Rosetta.

1. Find your printer

    Not listed? Try fewer words (just the model number). If it still isn't there, Gutenprint doesn't support that model — check whether macOS already sees it via AirPrint.

    2. Install (same package for every printer)

    1. Connect the printer to the Mac with a USB cable and switch it on.
    2. Download the installer (.pkg) from GitHub.
    3. Open Terminal (press ⌘+Space, type Terminal, Enter), paste this line and press Enter. Type your Mac password when asked (it stays invisible while typing): 
      sudo installer -pkg ~/Downloads/AppleSilicon-Printer-Drivers-1.3.1.pkg -target /
    4. The installer detects the printers on USB and creates them for you. If the printer maker's old driver was installed before: restart the Mac, then unplug and re-plug the printer once.

    3. Add the printer

    Was your printer plugged in during step 2? Then the installer most likely created it already — check System Settings → Printers & Scanners and just print. If it isn't there (or it's a Wi-Fi printer), paste the command shown for your model in step 1. Examples:

    PrinterCommand
    Canon PIXMA MP250sudo gutenprint-add bjc-MULTIPASS-MP250
    Canon PIXMA iP4300sudo gutenprint-add bjc-PIXMA-iP4300
    Epson Stylus Photo R300sudo gutenprint-add escp2-r300
    HP LaserJet 1010sudo gutenprint-add hp-lj_1010
    Brother HL-5040sudo gutenprint-add brother-hl-5040
    Samsung ML-2150sudo gutenprint-add samsung-ml-2150

    Questions

    Why does my Mac say “The printer software is not compatible with this device”?

    Your printer's driver was compiled for Intel Macs only. macOS 27 flags Intel-only printer software on Apple Silicon (M1–M4) Macs, and Rosetta, which used to run it, is being phased out. This site provides a native replacement.

    Which printers get set up automatically?

    Any printer connected over USB during installation whose USB name matches a model in the database — e.g. “Canon MP250 series”, “EPSON Stylus Photo R300”, “Brother HL-5040 series”. Others take one gutenprint-add command, shown when you search your model on this page.

    Is it free?

    Yes. It is the open-source Gutenprint driver (GPL-2.0), compiled natively for Apple Silicon and packaged as a one-click macOS installer.

    Does it remove my old driver?

    Only when it has to: Canon's IJ driver installs a kernel extension that blocks macOS's own USB printer driver, so the installer moves it to /Users/Shared/printer-driver-backup (nothing is deleted). Other vendors' drivers are left in place.

    Does the scanner of my all-in-one work?

    No. Only printing is covered. For scanning use SANE (Homebrew) or VueScan, which have native Apple Silicon support.

    My printer is on Wi-Fi, not USB.

    Install the package, then add the printer in System Settings → Printers & Scanners, choose Use: Select Software… and pick the entry ending in “Apple Silicon”.

    Which macOS versions?

    Built and tested on macOS 27 (Apple Silicon). It should work on macOS 12 and later on M-series Macs.

    How it works

    The package is Gutenprint 5.3.4 compiled for arm64 and installed under /Library/Printers/Gutenprint, where Apple's print system can run it, plus a small helper (gutenprint-add) that writes the printer description file and creates the queue. Printing goes through Apple's own USB printer class driver, so nothing Intel-only is involved. Full details, source and build scripts are on GitHub.
