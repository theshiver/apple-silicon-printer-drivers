Вопросы

Есть ли драйвер принтера NRG для macOS 27 и Apple Silicon?

Для многих старых принтеров NRG не выпустила драйверы Mac для Apple Silicon. Им нужна Rosetta, а macOS 27 помечает драйверы только для Intel как несовместимые. Apple отключает Rosetta для приложений в macOS 28. Этот бесплатный пакет добавляет нативные драйверы arm64 для 124 моделей NRG, поэтому они печатают на любом Mac с Apple Silicon без Rosetta.

Почему мой принтер NRG пишет «Программное обеспечение принтера несовместимо с этим устройством»?

Установленный на Mac драйвер принтера NRG работает только на Intel. Установите этот пакет, один раз перезагрузите Mac, затем отключите принтер и подключите заново.

Поможет ли переустановка Rosetta?

Иногда, и только пока. После переустановки Rosetta некоторые старые драйверы снова работают, если удалить принтер и добавить его заново. Другие остаются с пометкой «ПО несовместимо». Apple отключает Rosetta для приложений в macOS 28, поэтому старый драйвер производителя снова перестанет работать. Этому драйверу Rosetta не нужна.

Работает ли он в macOS 26 Tahoe и macOS 15 Sequoia?

Да. Он работает на macOS 12 и новее на компьютерах Mac с Apple Silicon и продолжает работать после обновления до macOS 27.

Мой принтер подключён по Wi-Fi или не настроился автоматически.

Установите драйвер, затем откройте Системные настройки → Принтеры и сканеры, нажмите Добавить, выберите свой принтер, выберите Использовать: Выбрать ПО… и укажите свою модель с пометкой «Apple Silicon».
