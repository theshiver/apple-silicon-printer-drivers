Why did my Canon PIXMA MG6110 stop working?

Canon's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta, but macOS 27 marks Intel-only printer drivers as incompatible, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with Gutenprint 5.3.5, compiled natively for Apple Silicon.

Had Canon's own driver installed? It leaves a small kernel extension behind that blocks macOS's USB printer driver. The installer moves it aside, nothing is deleted; restart the Mac once afterwards, then unplug and re-plug the printer.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.

Questions

Does the Canon PIXMA MG6110 work on macOS 27, macOS 26 Tahoe and Apple Silicon?

Yes. This free package adds a native arm64 Gutenprint driver for the Canon PIXMA MG6110. It runs on every Apple Silicon Mac with macOS 12 or later, including macOS 27, without Rosetta.

Do I need to write my own Canon PIXMA MG6110 driver?

No. The Canon PIXMA MG6110 is already supported by Gutenprint, an open source driver with years of tuning for this printer. Install the package; there is nothing to write, compile or patch.

Why does my Canon PIXMA MG6110 say “The printer software is not compatible with this device”?

Canon's Mac driver for the Canon PIXMA MG6110 is Intel-only, and macOS 27 marks Intel-only printer drivers as incompatible. Install this package, restart the Mac once, then unplug and re-plug the printer.

Advanced: set it up from Terminal

Driver: Gutenprint 5.3.5 · Model id: bjc-PIXMA-MG6110

sudo gutenprint-add bjc-PIXMA-MG6110

Network printer, with a name and its address:

sudo gutenprint-add bjc-PIXMA-MG6110 MyPrinter socket://192.168.1.50
