Driver: Gutenprint 5.3.5 · Model id: bjc-SmartBase-MPC600F

Wi-Fi, network, or not detected over USB

After installing, open Terminal (⌘+Space, type Terminal), paste this and press Enter:

sudo gutenprint-add bjc-SmartBase-MPC600F

For a network printer, add a name and the printer's address (lpinfo -v lists what macOS can see):

sudo gutenprint-add bjc-SmartBase-MPC600F MyPrinter socket://192.168.1.50

Or without Terminal: System Settings → Printers & Scanners → Add → Use: Select Software… and pick “Canon SmartBase MPC600F” ending in “Apple Silicon”.

Why did my Canon SmartBase MPC600F stop working?

Canon's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta, but macOS 27 marks Intel-only printer drivers as incompatible, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with Gutenprint 5.3.5, compiled natively for Apple Silicon.

Had Canon's own driver installed? It leaves a small kernel extension behind that blocks macOS's USB printer driver. The installer moves it aside (to /Users/Shared/printer-driver-backup, nothing is deleted); restart the Mac once afterwards, then unplug and re-plug the printer.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.

Questions

Does the Canon SmartBase MPC600F work on macOS 27, macOS 26 Tahoe and Apple Silicon?

Yes. This free package adds a native arm64 Gutenprint driver for the Canon SmartBase MPC600F. It runs on every Apple Silicon Mac with macOS 12 or later, including macOS 27, without Rosetta.

Do I need to write my own Canon SmartBase MPC600F driver?

No. The Canon SmartBase MPC600F is already supported by Gutenprint, an open source driver with years of tuning for this printer. Install the package; there is nothing to write, compile or patch.

Why does my Canon SmartBase MPC600F say “The printer software is not compatible with this device”?

Canon's Mac driver for the Canon SmartBase MPC600F is Intel-only, and macOS 27 marks Intel-only printer drivers as incompatible. Install this package, restart the Mac once, then unplug and re-plug the printer.
