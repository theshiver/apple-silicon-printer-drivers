Why did my Kyocera FS-1800+ stop working?

Kyocera's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta, but macOS 27 Golden Gate marks Intel-only printer drivers as incompatible, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with Gutenprint 5.3.5, compiled natively for Apple Silicon.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.

Questions

Does the Kyocera FS-1800+ work on macOS 27 Golden Gate, macOS 26 Tahoe and Apple Silicon?

Yes. This free package adds a native arm64 Gutenprint driver for the Kyocera FS-1800+. It runs on every Apple Silicon Mac with macOS 12 or later, including macOS 27 Golden Gate, without Rosetta.

Do I need to write my own Kyocera FS-1800+ driver?

No. The Kyocera FS-1800+ is already supported by Gutenprint, an open source driver with years of tuning for this printer. Install the package; there is nothing to write, compile or patch.

Why does my Kyocera FS-1800+ say “The printer software is not compatible with this device”?

Kyocera's Mac driver for the Kyocera FS-1800+ is Intel-only, and macOS 27 Golden Gate marks Intel-only printer drivers as incompatible. Install this package, restart the Mac once, then unplug and re-plug the printer.

Advanced: set it up from Terminal

Driver: Gutenprint 5.3.5 · Model id: kyocera-fs-1800plus

sudo gutenprint-add kyocera-fs-1800plus

Network printer, with a name and its address:

sudo gutenprint-add kyocera-fs-1800plus MyPrinter socket://192.168.1.50
