Kyocera printer driver for Mac (Apple Silicon, macOS 27)

119 Kyocera printers work again on Apple Silicon Macs with macOS 27 Golden Gate, macOS 26 Tahoe and macOS 15 Sequoia. One free installer for all of them, no Rosetta.

Free · Signed and notarized by Apple · Any Apple Silicon Mac, macOS 12 or later

  2. Open the downloaded file and click through
  3. Print. The printer is set up for you

Questions

Is there a Kyocera printer driver for macOS 27 and Apple Silicon?

Kyocera never released Apple Silicon versions of the Mac drivers for many of its older printers; they need Rosetta, and macOS 27 marks Intel-only printer drivers as incompatible. Apple ends Rosetta for apps in macOS 28. This free package adds native arm64 drivers for 119 Kyocera models, so they print on any Apple Silicon Mac without Rosetta.

Why does my Kyocera printer say “The printer software is not compatible with this device”?

The Kyocera driver installed on the Mac is Intel-only. Install this package, restart the Mac once, then unplug and re-plug the printer.

Will reinstalling Rosetta fix it?

Sometimes, and only for now. Reinstalling Rosetta makes some old printer drivers work again after you delete and re-add the printer; others stay marked “Software Incompatible”. Apple ends Rosetta for apps in macOS 28, so the maker's old driver will stop again then. This driver doesn't need Rosetta.

Does it work on macOS 26 Tahoe and macOS 15 Sequoia?

Yes. It runs on macOS 12 and later on Apple Silicon Macs, and keeps working after you update to macOS 27.

My printer is on Wi-Fi, or wasn't set up automatically.

Install the driver, then open System Settings → Printers & Scanners, click Add, select your printer, choose Use: Select Software… and pick your model ending in “Apple Silicon”.
