Questions

Is there a Apollo printer driver for macOS 27 and Apple Silicon?

Apollo never released Apple Silicon versions of the Mac drivers for many of its older printers; they need Rosetta, which the macOS 27 upgrade removes and Apple ends for apps in macOS 28. This free package adds native arm64 drivers for 8 Apollo models, so they print on any Apple Silicon Mac without Rosetta.

Why does my Apollo printer say “The printer software is not compatible with this device”?

The Apollo driver installed on the Mac is Intel-only. Install this package, restart the Mac once, then unplug and re-plug the printer.

Will reinstalling Rosetta fix it?

Sometimes, and only for now. Running softwareupdate --install-rosetta in Terminal brings Rosetta back, and some Intel-only printer drivers work again after you delete and re-add the printer; others stay marked “Software Incompatible”. Apple ends Rosetta for apps in macOS 28, so the maker's Intel-only driver will stop again then. This package is native arm64 and doesn't need Rosetta.

Does it work on macOS 26 Tahoe and macOS 15 Sequoia?

Yes. It runs on macOS 12 and later on Apple Silicon Macs, and keeps working after you update to macOS 27.
