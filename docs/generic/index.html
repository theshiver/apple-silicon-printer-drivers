Generic printer drivers for Apple Silicon Macs

20 Generic models work on M-series Macs with this free, native (arm64) driver — no Rosetta, no Generic software needed.

Search your exact model instead: use the search box on the home page — it shows the one command you need.

1. Install the driver package (same for every model)

  1. Connect the printer to the Mac with a USB cable and switch it on.
  2. Download the installer (.pkg) from GitHub.
  3. Open Terminal (press ⌘+Space, type Terminal, Enter), paste this line and press Enter. Type your Mac password when asked (it stays invisible while typing): 
    sudo installer -pkg ~/Downloads/AppleSilicon-Printer-Drivers-1.3.1.pkg -target /
  4. The installer detects the printers on USB and creates them for you. If the printer maker's old driver was installed before: restart the Mac, then unplug and re-plug the printer once.

2. Add your Generic printer

Find your model in the table, paste its command into Terminal and press Enter. The printer queue is created automatically when the printer is connected over USB.

Network / Wi-Fi printer? Add the device address: sudo gutenprint-add <id> MyPrinter socket://192.168.1.50 (lpinfo -v lists what macOS sees), or add it in System Settings → Printers & Scanners → Use: Select Software… and pick the "Apple Silicon" entry.
