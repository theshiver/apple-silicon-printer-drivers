Why did my Epson Stylus CX8400 stop working?

Epson's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta, but macOS 27 marks Intel-only printer drivers as incompatible, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with Gutenprint 5.3.5, compiled natively for Apple Silicon.

Black missing or faint? Run a nozzle check from the printer first: a clogged or empty black cartridge is the usual cause, and this driver can't read ink levels like Epson's did. Then make sure no color-only mode is picked under Resolution or Ink Set in Printer Features.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.

Questions

Does the Epson Stylus CX8400 work on macOS 27, macOS 26 Tahoe and Apple Silicon?

Yes. This free package adds a native arm64 Gutenprint driver for the Epson Stylus CX8400. It runs on every Apple Silicon Mac with macOS 12 or later, including macOS 27, without Rosetta.

Do I need to write my own Epson Stylus CX8400 driver?

No. The Epson Stylus CX8400 is already supported by Gutenprint, an open source driver with years of tuning for this printer. Install the package; there is nothing to write, compile or patch.

Why does my Epson Stylus CX8400 say “The printer software is not compatible with this device”?

Epson's Mac driver for the Epson Stylus CX8400 is Intel-only, and macOS 27 marks Intel-only printer drivers as incompatible. Install this package, restart the Mac once, then unplug and re-plug the printer.

Advanced: set it up from Terminal

Driver: Gutenprint 5.3.5 · Model id: escp2-cx8400

sudo gutenprint-add escp2-cx8400

Network printer, with a name and its address:

sudo gutenprint-add escp2-cx8400 MyPrinter socket://192.168.1.50
