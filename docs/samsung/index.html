Samsung printer driver for Mac (Apple Silicon, macOS 27)

97 Samsung printers work again on M1, M2, M3 and M4 Macs with macOS 27, macOS 26 Tahoe and macOS 15 Sequoia. Free native driver, no Rosetta. Install once, print again.

Looking for your exact model? Pick it in the table below for model-specific instructions, or search on the home page.

Install (same package for every model)

  1. Plug the printer into the Mac with a USB cable and switch it on.
  2. Download the installer (.pkg) and open it. Click through, enter your Mac password. It is signed and notarized by Apple, so there are no security warnings.
  3. Print something. The installer recognised the printer and set it up as the default.

Still not printing? Restart the Mac once and unplug / re-plug the printer. Then see below.

Printer not set up automatically?

USB printers are normally detected by the installer. If yours wasn't (or it's on Wi-Fi), find it below, open Terminal (⌘+Space, type Terminal), paste its command and press Enter.

Questions

Is there a Samsung printer driver for macOS 27 and Apple Silicon?

Samsung never released Apple Silicon versions of the Mac drivers for many of its older printers; they ran through Rosetta, which macOS 27 no longer allows. This free package adds native arm64 drivers for 97 Samsung models, so they print on M1, M2, M3 and M4 Macs without Rosetta.

Why does my Samsung printer say “The printer software is not compatible with this device”?

The Samsung driver installed on the Mac is Intel-only. Install this package, restart the Mac once, then unplug and re-plug the printer.

Does it work on macOS 26 Tahoe and macOS 15 Sequoia?

Yes. It runs on macOS 12 and later on Apple Silicon Macs, and keeps working after you update to macOS 27.
