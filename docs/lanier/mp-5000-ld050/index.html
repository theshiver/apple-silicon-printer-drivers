Lanier MP 5000/LD050 driver for Mac

The Lanier MP 5000/LD050 works on Apple Silicon Macs and macOS 27 with this free, native arm64 macOS printer driver. No Rosetta, no Intel-only software from the printer maker.

✅ Lanier MP 5000/LD050 is supported. Driver: Gutenprint 5.3.5. Model id: lanier-ld050

Install the Lanier MP 5000/LD050 driver

  1. Plug the printer into the Mac with a USB cable and switch it on.
  2. Download the installer (.pkg) and open it. Click through, enter your Mac password. It is signed and notarized by Apple, so there are no security warnings.
  3. Print something. The installer recognised the printer and set it up as the default.

Still not printing? Restart the Mac once and unplug / re-plug the printer. Then see below.

Wi-Fi, network, or not detected over USB

After installing, open Terminal (⌘+Space, type Terminal), paste this and press Enter:

sudo gutenprint-add lanier-ld050

For a network printer, add a name and the printer's address (lpinfo -v lists what macOS can see):

sudo gutenprint-add lanier-ld050 MyPrinter socket://192.168.1.50

Or without Terminal: System Settings → Printers & Scanners → Add → Use: Select Software… and pick “Lanier MP 5000/LD050” ending in “Apple Silicon”.

Why did my Lanier MP 5000/LD050 stop working?

Lanier's own Mac driver for this printer was built for Intel Macs only. On Apple Silicon it ran through Rosetta until macOS 27, which no longer allows that, so System Settings now says “The printer software is not compatible with this device”. This package replaces it with Gutenprint 5.3.5, compiled natively for Apple Silicon.

Print quality and black & white: in the print dialog open Printer Features (Printer Options on macOS 27). Quality is under Resolution; for black & white set Color Model to Grayscale. Ink and toner levels can't be shown by open source drivers.
