Should you reinstall Rosetta for your printer on macOS 27?

macOS 27 Golden Gate drops Rosetta 2 by default during the upgrade, breaking Intel-only printer drivers. Here is when reinstalling Rosetta works, why it stops again in macOS 28, and how to fix your printer natively instead.

Why macOS 27 Golden Gate broke your printer

Older Canon, Brother, Epson, HP and Samsung drivers ship Intel-only CUPS filters inside /Library/Printers/. When macOS 27 upgrades without Rosetta 2, CUPS cannot execute those binaries. System Settings shows “The printer software is not compatible with this device”, or the print queue logs Bad CPU type in executable.

Unlike regular Mac apps, background printer filters do not trigger a macOS popup asking to install Rosetta.

Option A: Reinstall Rosetta 2 (temporary bridge)

If you only want your vendor driver back for now, Apple still lets you install Rosetta 2 manually in macOS 27:

softwareupdate --install-rosetta --agree-to-license
  1. Run the command above in Terminal and wait for it to finish.
  2. Open System Settings → Printers & Scanners and remove the broken printer queue.
  3. Restart your Mac, then add the printer again.

Where Rosetta falls short: some vendor drivers still fail signature or filter checks on macOS 27 even after Rosetta is installed, and Apple ends general Rosetta support for apps in macOS 28.

Option B: Native Apple Silicon drivers (permanent, no Rosetta)

Instead of translating old Intel filters, you can install native arm64 open-source drivers compiled specifically for Apple Silicon Macs (Gutenprint, brlaser, SpliX and foo2zjs). They run directly on M1–M4+ Macs with no Rosetta dependency and keep working across macOS updates.

Questions

What if reinstalling Rosetta didn't fix my printer?

Remove the old printer entry in System Settings → Printers & Scanners, install the native Apple Silicon driver package above, restart once, and add the printer using the entry ending in “Apple Silicon”.

Does this driver work alongside Rosetta?

Yes. Native arm64 filters do not conflict with Rosetta 2, and if you had Canon's older Intel USB driver installed, the installer safely moves the blocking kernel extension aside without deleting it.

Will Apple remove Rosetta completely?

Apple announced that macOS 27 is the final release with general Rosetta 2 support for Intel apps, ending in macOS 28. Native arm64 drivers do not use Rosetta at all.
