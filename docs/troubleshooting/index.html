Printer still not working after installing?

Fixes for the problems people hit after installing the driver package, in the order they usually happen.

It still says “The printer software is not compatible with this device” after installing.

That message belongs to the old printer entry, which still uses the maker's Intel-only driver. The installer adds a new entry next to it, named after the model and ending in “Apple Silicon”. In System Settings → Printers & Scanners, remove the old entry (select it, click −), then print to the “Apple Silicon” one. If there is no such entry, restart the Mac once, unplug and re-plug the printer, and check the next question.

My printer doesn't show up in the list.

Search your model on the home page first: if it isn't supported, no entry will appear. If it is supported and connected over USB, restart the Mac once and unplug / re-plug the printer, and connect it directly rather than through a hub or dock. Then add it in System Settings → Printers & Scanners → Add, with Use: Select Software… and the entry for your model ending in “Apple Silicon”.

“Software for this printer isn't available from Apple”.

macOS shows this when you add a printer it has no driver for. Install this package first, then add the printer again in System Settings → Printers & Scanners → Add, choose Use: Select Software… and pick the entry for your model ending in “Apple Silicon”.

“No AirPrint printers found”, or AirPrint isn't offered.

Older printers don't support AirPrint, and AirPrint never works over USB. For those printers, add them with Use: Select Software… and the “Apple Silicon” entry, after installing this package.

My printer is on Wi-Fi or Ethernet.

The installer only sets up USB printers by itself. For a network printer, add it in System Settings → Printers & Scanners → Add with Use: Select Software… and the “Apple Silicon” entry. If the printer doesn't appear, connect it to the same network as the Mac and switch it off and on.

Will reinstalling Rosetta fix it?

Sometimes, and only for now. Reinstalling Rosetta makes some old printer drivers work again after you delete and re-add the printer; others stay marked “Software Incompatible”. Apple ends Rosetta for apps in macOS 28, so the maker's old driver will stop again then. This driver doesn't need Rosetta.

The job goes through but nothing prints, or only blank pages.

Check that the queue uses your exact model: a similar model's driver can send data the printer silently ignores. Some printers, such as the HP LaserJet 1018, 1020, P1005 and P1006, can't be supported at all because they need the maker's firmware sent on every power-up.

Nothing here helped.

Open an issue on GitHub (https://github.com/theshiver/apple-silicon-printer-drivers/issues) with your printer model, how it's connected (USB or network) and your macOS version. Terminal steps for advanced users are in the README on GitHub.
